# Expresión Gráfica · Guía para aprobar (UPCT, GIEyA)

Guía de estudio no oficial de Expresión Gráfica (1.º GIEyA, UPCT), construida con las presentaciones del curso 2021/22 (construcciones geométricas, diédrico, axonométrico, normalización, vistas y cortes, acotación, roscas, acabado superficial, tolerancias dimensionales y geométricas, conjuntos, CAD, esquemas eléctricos), los apuntes y «Exámenes anteriores resueltos» 2005-2012: 14 temas con figuras interactivas (polígonos y estrellados, cónicas con focos, el punto en los cuatro diedros, isométrica/caballera, formatos y escalas, de la pieza a sus vistas, acotación, designación de roscas, símbolo de acabado, calculadora de ajustes ISO con las tablas del examen, tolerancias geométricas, test de conjuntos, transformaciones con matrices y simulador de contactor), 15 ejercicios de examen resueltos y verificados con las tablas ISO, 13 preguntas de desarrollo con guion de respuesta, el análisis de 8 años de exámenes y chuleta final.

Web: https://helionacon-ui.github.io/Expresi-n-gr-fica/ · Índice de guías: https://helionacon-ui.github.io/GIEIA-UPCT/

Sitio estático (HTML + CSS + JS). Sin dependencias ni build.
