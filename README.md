# Expresión Gráfica · Guía para aprobar (UPCT, GIEyA)

Guía de estudio no oficial de Expresión Gráfica (1.º GIEyA, UPCT), construida con las presentaciones del curso 2021/22 (construcciones geométricas, diédrico, axonométrico, normalización, croquización, acotación, roscas, acabado superficial, tolerancias dimensionales y geométricas, conjuntos, CAD), los apuntes de diédrico y potencia, y los exámenes resueltos 2005-2012: 14 temas con 14 figuras interactivas (polígonos, cónicas, diédrico, isométrica/caballera, formatos y escalas, vistas y cortes, acotación, designación de roscas, símbolo de acabado, calculadora de ajustes ISO con las tablas del examen, tolerancias geométricas, test de conjuntos, transformaciones con matrices y simulador de marcha-paro con contactor), las preguntas de desarrollo respondidas y 16 problemas de examen resueltos y verificados.

Web: https://helionacon-ui.github.io/Expresi-n-gr-fica/ · Índice de guías: https://helionacon-ui.github.io/GIEIA-UPCT/

Sitio estático (HTML + CSS + JS). Sin dependencias ni build.
